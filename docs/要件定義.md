# 📘 要件定義書：ポーランド語学習アプリ「PolishMate

## 📝 概要

- **アプリ名（通称）*：PolishMae
- **リポジトリ名*：polishmae
- **対象ユーザー*：開発者本人（ポーランド在住の日本）
- **目的*：ポーランド語の会話力上
- **初期プラットフォーム**: Web（モバイル／デスクトップ対応、将来的にPWA化やモバイルラッパーも検討）
- **初期開発目標**: 開発者自身のブラウザ（PC／スマホ）で動作させる（公開は初期フェーズでは対象外）
- **マネタイズ*：なし（広告・課金な）
- **デプロイ環境**: Vercel（mainブランチへのコミットで自動デプロイ）

## 🛠 技術スタック

- **フレームワーク**: React（Next.js 14, TypeScript）
- **データベース*：Supabase（PostgreSQL、認証機能む）
- **音声認識**: Web Speech API（`SpeechRecognition` インターフェース）
- **音声合成**: Web Speech API（`SpeechSynthesis` インターフェース）

## 🔑 コア機能

### 1. 📚 単語・フレーズ学

- カテゴリ別にポーランド語のフレーズを収録（例：「カフェで」「病院」など
- 各フレーズに音声再生機能を搭載（Google TTを使用）

### 2. ✅ クイズ形式の確

- 4択またはYes/No形式のクズを提
- 音声再生後、対応する日本語を選する形式

### 3. 🎤 発音練習（音声入）

- ユーザーがポーランド語を発音し、音声認識テキス化
- 正解フレーズとの一致度を表示し、発音精度を確認

### 4. ⭐ お気に入り録

- 学習中のフレーズをお気に入りに追加し、で復習可能

### 5. 📈 進管理

- 学習したフレーズ数やクイズの正率などを記録

## 🔌 データ構成（Supabase想定）

- users`：ユーザー情報（ユーザーのみ）
- `prases`：フレーズデータ（ポーランド語、日本語、カテゴリ、声URLなど）
- `qizzes`：イズ問題セット
- `favrites`：お気に入り管理
-`logs`学習ログ記録

## 🧩 音声機能の実装詳細

### 音声認識（Web Speech API）

- ブラウザ標準の Web Speech API (`SpeechRecognition`) を使用し、音声入力をテキスト化
- ユーザーの発音をリアルタイムでテキスト化し、正解フレーズとの比較を行う

### 音声合成（Web Speech API）

- ブラウザ標準の Web Speech API (`SpeechSynthesis`) を使用し、ポーランド語のフレーズを自然な音声で再生

## 🔍 除外事項

- 文字入力よる学や検索機能
- 他ーザーの共有機能
- マネタイズ要（広告、課金など）
