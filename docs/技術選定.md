# 技術選定

## フレームワーク／ランタイム

- **React（Next.js 14, TypeScript）**
  - SSR / SSG / SPA を統合的に扱える App Router 採用
  - Vercel をはじめとするホスティングとの親和性が高い
  - React 18 の Concurrent Feature によりインタラクションが滑らか

- **API サーバー**
  - **Hono**（Node.js／Deno 対応）
    - 軽量かつ高速なルーティング
    - TypeScript サポート

## データベース／認証

- **Supabase (PostgreSQL)**
  - リアルタイム DB／認証／ストレージをフルマネージドで提供
  - SQL や JSONB、Row-Level Security をサポート
  - CLI／Dashboard でスキーマ管理が容易

## 音声機能

- **音声認識 / 音声合成**
  - ブラウザ標準 Web Speech API を利用
  - `SpeechRecognition` で音声→テキスト変換
  - `SpeechSynthesis` でテキスト→音声合成
  - クロスブラウザ差異に留意（特に iOS Safari）

## その他ライブラリ／ツール

- **State Management**: React Query / Zustand
- **HTTP クライアント**: Axios
- **認証連携**: Supabase JS SDK
- **テスト**: Jest + React Testing Library, Playwright (E2E)
- **CI/CD**: GitHub Actions  

## デプロイ環境

- **Vercel**
  - Next.js の開発元が提供する最適化されたホスティングサービス
  - GitHub リポジトリとの連携で main ブランチへのコミット検知時に自動デプロイ
  - プレビューデプロイも自動生成（PR 作成時）
  - カスタムドメイン・HTTPS 対応
