# 技術選定

## フレームワーク／ランタイム

- **Flutter**
  - クロスプラットフォーム開発（iOS/Android）に最適
  - Dart 言語でステートフル UI を効率的に設計可能
  - Google のサポートがあり、音声関連プラグインとの親和性も高い

- **API サーバー**
  - **Hono**（Node.js／Deno 対応）
    - 軽量かつ高速なルーティング
    - TypeScript サポート

## データベース／認証

- **Supabase (PostgreSQL)**
  - リアルタイム DB／認証／ストレージをフルマネージドで提供
  - SQL や JSONB、Row-Level Security をサポート
  - CLI／Dashboard でスキーマ管理が容易

## 音声機能

- **音声認識 (Speech-to-Text)**
  - パッケージ: `google_speech` (Flutter)
  - 背後に Google Cloud Speech-to-Text API
  - リアルタイムストリーミング対応

- **音声合成 (Text-to-Speech)**
  - パッケージ: `cloud_text_to_speech` (Flutter)
  - 背後に Google Cloud Text-to-Speech API
  - 多彩なポーランド語音声サポート

## その他ライブラリ／ツール

- **State Management**: Riverpod / Provider
- **HTTP クライアント**: Dio
- **認証連携**: Supabase Auth SDK
- **テスト**: Flutter Test, Jest (API 層)
- **CI/CD**: GitHub Actions
